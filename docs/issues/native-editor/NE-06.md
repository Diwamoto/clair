# NE-06: コメントanchorを編集・Undoに追従させる

- 状態: open
- 優先度: P1
- 依存: [NE-02](NE-02.md)
- 担当範囲: 新規コメントanchorモデルとテスト
- 作成日: 2026-09-08

## 目的と前提

コメントanchorを編集・Undoに追従させる。これはネイティブエディタPoCの残作業であり、本番への無条件採用は決定していない。
開始前に[共通ルールと基準](README.md)、[PoC報告](evidence/poc-report.md)を読む。NE-00完了後のソースを基準にし、依存Issueの成果コミットと完了条件を確認してから着手する。

## 実施手順

1. ファイルID、範囲、revision、コメントID、active/orphan状態をモデル化する。コード本文と別保存とする。
2. 挿入・削除・置換・複数編集transactionによる範囲移動を実装し、範囲の端への挿入時の所属ルールを明記する。
3. 対象削除でorphan化し、その削除をUndoしたとき同じ対象に戻せるようtransaction履歴と結び付ける。文字列検索だけで再接続しない。
4. ローカル保存/再読込のschemaを作り、文書revisionが一致しない場合に誤接続しない経路を実装する。

## 完了条件・検証

1. 対象前・内部・境界の編集、全削除、複数カーソル、Undo/Redo、保存再読込のテストが通る。
2. 同じ文字列が複数箇所にあっても別箇所へコメントが移らない。
3. 復元不能な外部変更はorphanとして表示用に返す。

## 対象外

クラウド共有、外部サービス同期、コメントUI。

## 引き継ぎ時に記録するもの

- 変更したファイルと成果コミットSHA（共有の指示なしにpushしない）。
- 実行したコマンド、環境、入力fixture、期待結果と実結果、証跡への相対リンク。
- 未検証・既知の制限。実行不能の場合は状態をblockedにし、不足している入力/環境を具体的に書く。
- 完了条件を満たした場合だけdoneに変更する。後続Issueの依存欄に共有可能な成果を追記する。
