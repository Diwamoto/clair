## 目的と前提

PoCを再現可能な共有ベースへ移す。これはネイティブエディタPoCの残作業であり、本番への無条件採用は決定していない。
開始前に[共通ルールと基準](README.md)、[PoC報告](evidence/poc-report.md)を読む。NE-00完了後のソースを基準にし、依存Issueの成果コミットと完了条件を確認してから着手する。

## 実施手順

1. 元PoC /Users/daiki/.codex/worktrees/afc2/clair/prototypes/native-editor-poc を読み、変更状態と全ソースのSHA-256を記録する。元worktreeを編集しない。
2. .build、生成fixture、キャッシュを除くソース・固定依存・生成スクリプト・証跡を作業ブランチへ取り込む。既存ファイルがあれば差分を比較し、上書きしない。
3. READMEの手順でReleaseビルド、fixture生成、--self-testを実行する。外部依存の取得失敗とコードの失敗を区別する。
4. 共有用のコミットを作り、そのSHAと再現手順を本Issueに記録する。push不要。後続はこのコミットを含む隔離ブランチで開始する。

2. 必須self-testが終了コード0。上流Undoのexpected failureは別表示し、成功数へ混ぜない。
3. Package.resolved、fixture hash、ソースrevision、実行ログへのリンクが揃う。
