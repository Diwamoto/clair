# NE-03: 実IME・Unicode操作・Undoの不具合を潰す

- 状態: open
- 優先度: P0
- 依存: [NE-00](NE-00.md)
- 担当範囲: PoC入力adapterと入力回帰テスト
- 作成日: 2026-09-08

## 目的と前提

実IME・Unicode操作・Undoの不具合を潰す。これはネイティブエディタPoCの残作業であり、本番への無条件採用は決定していない。
開始前に[共通ルールと基準](README.md)、[PoC報告](evidence/poc-report.md)を読む。NE-00完了後のソースを基準にし、依存Issueの成果コミットと完了条件を確認してから着手する。

## 実施手順

1. PoCのstorage delegate/Undo grouping adapterを読み、上流既定の失敗と補正後を分けて再現する。
2. 日本語IMEで「にほんご」の変換、候補変更、確定、Esc取消、再変換、変換中のタブ切替・保存を実操作する。OS/IME名と操作列を記録する。
3. 家族emoji、結合文字、日本語混在文で矢印、ドラッグ、Backspace/Delete、コピー貼付を行う。
4. 単一/複数カーソルの入力、改行、貼付、削除、IME確定を各1回Undo/Redoして確認し、問題をadapterで修正する。変換途中の編集を誤ってまとめない。

## 完了条件・検証

1. 各ケースの入力前/後/Undo後/Redo後の本文・選択と合否を記録する。
2. 候補UIがカーソルに追従し、変換文字の重複・欠落、grapheme分断、Undo履歴の混線がない。
3. 実IMEを操作できない場合は未検証で止め、合成APIテストで代替合格にしない。

## 対象外

新しいIME自作、通常版への既定切替。

## 引き継ぎ時に記録するもの

- 変更したファイルと成果コミットSHA（共有の指示なしにpushしない）。
- 実行したコマンド、環境、入力fixture、期待結果と実結果、証跡への相対リンク。
- 未検証・既知の制限。実行不能の場合は状態をblockedにし、不足している入力/環境を具体的に書く。
- 完了条件を満たした場合だけdoneに変更する。後続Issueの依存欄に共有可能な成果を追記する。
