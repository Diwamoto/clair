# NE-01: 配布依存と必要言語の許諾を確定する

- 状態: blocked
- 優先度: P0
- 依存: [NE-00](NE-00.md)
- 担当範囲: 依存監査文書、THIRD_PARTY_NOTICES案

## 目的と前提

配布依存と必要言語の許諾を確定する。これはネイティブエディタPoCの残作業であり、本番への無条件採用は決定していない。
開始前に[共通ルールと基準](README.md)、[PoC報告](evidence/poc-report.md)を読む。NE-00完了後のソースを基準にし、依存Issueの成果コミットと完了条件を確認してから着手する。

## 実施手順

1. Package.resolvedとPoC dependencies.json/grammar-source-pins.jsonを突き合わせ、直接・間接・バイナリ内依存を列挙する。
2. CodeEditLanguagesとCodeEditSymbolsの固定revisionで許諾根拠を確認する。LICENSE不在を許諾ありと推定しない。
3. Swift/Rust/TS/TSX/JSON/Markdownのgrammarとquery、Unicodeデータ、アイコンの出典・ライセンス・必要noticeを個別に表にする。
4. 許諾不明なものは未解決として根拠を残し、必要言語のソースビルドやアイコン置換で除去できるか具体案を作る。連絡や購入は行わない。

## 監査結果（2026-09-08）

- 状態は `blocked`。依存・資産の調査と証跡化は完了したが、通常版の配布許諾は未完了である。
- `Package.resolved` と `evidence/dependencies.json` の11 pinを突合し、root直接依存、間接runtime、build-time plugin、test-only依存を区別した。
- `CodeEditLanguages` の `CodeLanguagesContainer.xcframework.zip`（SHA-256 `c6ee69d9d373a9c3cf93d239e05369d9b941275d31cd7956d0dc83b5a5c3e152`、34,388,755 bytes）と、37 grammar source pin、81 query/resource filesの対応を記録した。
- PoCで実行した Swift/Rust/TS/TSX/JSON/Markdown のqueryファイルhash、Swift grammarのMIT LICENSE、tree-sitter内ICU subsetのUnicode notice、CodeEditSymbolsの33 asset filesを記録した。
- CodeEditLanguages/CodeEditSymbolsのroot LICENSE/NOTICE不在、grammar別notice未収録、binary-to-source対応未証明、SF Symbols asset provenance未確定を配布ゲートとして明示した。
- 監査本文: [`license-audit.md`](evidence/license-audit.md)。notice案: [`THIRD_PARTY_NOTICES.md`](evidence/THIRD_PARTY_NOTICES.md)。リポジトリのnotice正本にも未配布ゲートを追記した: [`THIRD_PARTY_NOTICES.md`](../../../THIRD_PARTY_NOTICES.md)。
- 判定: **通常版を配布可能か — no**。NE-11/NE-15はこのゲートを通過するまで通常経路・本番資産を変更しない。

### 未解決事項と後続Issue案

CodeEditLanguagesの37 grammarについて、各固定revisionのlicense/noticeを収集し、必要6言語だけをsource buildしてparser/query/licenseを同一manifestでhash固定するか、CodeEditLanguagesの再配布根拠を取得する必要がある。CodeEditSymbolsはasset単位の出典確認または独自SVGへの置換が必要である。これは法務・外部許諾に関わるため、本Issueでは問い合わせ・購入・置換実装を行わない。後続のremediation Issueを作成し、通常版採用前の必須依存として設定する。

## 検証記録

- 環境: macOS 26.6.2、Apple M4、NE-00で解決済みのSwiftPM checkout。共有worktreeのソースは変更していない。
- `python3` の突合チェック: `Package.resolved` と `evidence/dependencies.json` は11/11 identity/location/revision/version一致。`grammar-source-pins.json` は37 pin、originHash `c940c7467f54711e27ceb0cef308954e1fdbcc20f3dd59d96d6efbe29d7a04ba`。
- 固定checkout確認: 全9 license-bearing SwiftPM packageのlicense file hashが `dependencies.json` と一致。CodeEditLanguages/CodeEditSymbolsにはroot LICENSE/NOTICEなし。CodeLanguagesContainer zipは `unzip -t` で破損なし。
- resource確認: 必要6言語のquery合計13ファイルが存在し、PoC `checks-shared.log` のparser/query存在確認と一致。queryの存在はlicense許諾やbinary対応の証明として扱っていない。
- Unicode確認: tree-sitter `lib/src/unicode/LICENSE` が存在し、ICU source commitとUnicode/ICU noticeが別に必要であることを確認。
- 本文の根拠・hash・固定URL・具体的な除去/置換案は [`license-audit.md`](evidence/license-audit.md) に集約した。

## 完了条件・検証

1. 各配布物に固定ソース、許諾根拠URL/ファイル、notice、バイナリとの対応がある。
2. 不明項目が残る場合は配布不可のゲートとして明示し、除去/置換の追加Issueを作る。調査完了と配布許諾完了を区別する。
3. 通常版を配布可能かyes/noで判定できる。
