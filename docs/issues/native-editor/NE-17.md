# NE-17: 通常エディタの操作・設定・タブ復元を製品へ接続する

- 状態: open
- 種別: 本番実装
- 依存: [NE-03](NE-03.md), [NE-04](NE-04.md), [NE-05](NE-05.md), [NE-16](NE-16.md)
- 担当範囲: ContentView、エディタadapter、設定・navigation
- 作成日: 2026-09-08

## 目的・着手条件

通常エディタの操作・設定・タブ復元を製品へ接続する。調査報告やPoCだけでは完了にならない。Clairの本番コードへ実装し、製品経路で検証する。
[共通ルール](README.md)を読み、依存の成功SHAを含む隔離worktreeで作業する。NE-13の判断が不採用ならCodeEdit依存の本番実装を開始せず、代案を決定する追加Issueを作る。未達ゲートを無視しない。
UI変更は既存のClairデザインを維持する。新規UIが必要な場合は該当design/mock skillに従って先に仕様を確立し、本Issueにリンクする。

## 実施手順

1. 既存UIからフォント/折返し、検索結果ジャンプ、保存、Undo/Redo等の操作一覧を作り、各操作の接続先を決める。
2. マルチカーソル、検索置換、インデント、括弧対応、折畳みをnativeへ接続する。既存キー割当と衝突する場合は既存を優先し、代替を文書化する。
3. タブ切替時の文書・選択・scroll・Undoを維持する。再起動時は既存の保存対象に従ってpath/位置を復元し、Undo永続化を勝手に追加しない。
4. NE-05の大規模file制限とNE-03のIME adapterを本番で動かす。VoiceOver/キーボードフォーカスを操作確認する。

## 完了条件・検証

1. 操作一覧の各項目に実装箇所・合否・証跡がある。
2. 実IME中のタブ操作、検索ジャンプ、マルチカーソルUndo、設定変更後の選択位置が正しい。
3. 同じタブへ戻って再生成されず、closeで文書が解放される。

## 対象外

新しい画面デザイン、Web経路削除。

## 成果の引き継ぎ

変更ファイル、成功コミットSHA、実行コマンド、期待値と実結果、証跡へのリンクを追記する。必須項目が未検証ならdoneにしない。失敗時は再現手順・影響・不足条件を記録する。既存ユーザー変更をstageしない。push/外部公開はしない。
