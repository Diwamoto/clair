# NE-15: 本番用エディタ依存・資産をビルドへ組み込む

- 状態: open
- 種別: 本番実装
- 依存: [NE-01](NE-01.md), [NE-13](NE-13.md)
- 担当範囲: Xcode依存設定、grammar/query、notice、ビルドスクリプト
- 作成日: 2026-09-08

## 目的・着手条件

本番用エディタ依存・資産をビルドへ組み込む。調査報告やPoCだけでは完了にならない。Clairの本番コードへ実装し、製品経路で検証する。
[共通ルール](README.md)を読み、依存の成功SHAを含む隔離worktreeで作業する。NE-13の判断が不採用ならCodeEdit依存の本番実装を開始せず、代案を決定する追加Issueを作る。未達ゲートを無視しない。
UI変更は既存のClairデザインを維持する。新規UIが必要な場合は該当design/mock skillに従って先に仕様を確立し、本Issueにリンクする。

## 実施手順

1. NE-11の実験統合を棚卸しし、本番に残せる部分を再利用する。PoCの絶対パスや.build内の手修正に依存しない構成へ移す。
2. 許諾を確認した必要言語・アイコンだけを固定revisionで組み込み、queryのbundle参照を正式なアプリ資産配置に対応させる。
3. Stable/Dev双方のローカルReleaseビルドで依存解決と資産収録を確認する。未取得依存にはネットワークが必要なことを手順に明記する。
4. THIRD_PARTY_NOTICESと依存更新手順を更新する。

## 完了条件・検証

1. クリーンな作業場所から手動パッチなしでビルドできる。
2. 生成app内に6言語のqueryが存在し、実アプリの各言語でハイライトが動く。
3. ライセンス不明な配布物、元PoCの絶対パス参照がない。

## 対象外

既定切替、署名証明書変更、公開。

## 成果の引き継ぎ

変更ファイル、成功コミットSHA、実行コマンド、期待値と実結果、証跡へのリンクを追記する。必須項目が未検証ならdoneにしない。失敗時は再現手順・影響・不足条件を記録する。既存ユーザー変更をstageしない。push/外部公開はしない。
