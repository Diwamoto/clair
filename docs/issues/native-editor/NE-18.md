# NE-18: 行操作と永続コメントを本番エディタへ接続する

- 状態: open
- 種別: 本番実装
- 依存: [NE-06](NE-06.md), [NE-07](NE-07.md), [NE-17](NE-17.md)
- 担当範囲: コメント保存adapter、行操作UI
- 作成日: 2026-09-08

## 目的・着手条件

行操作と永続コメントを本番エディタへ接続する。調査報告やPoCだけでは完了にならない。Clairの本番コードへ実装し、製品経路で検証する。
[共通ルール](README.md)を読み、依存の成功SHAを含む隔離worktreeで作業する。NE-13の判断が不採用ならCodeEdit依存の本番実装を開始せず、代案を決定する追加Issueを作る。未達ゲートを無視しない。
UI変更は既存のClairデザインを維持する。新規UIが必要な場合は該当design/mock skillに従って先に仕様を確立し、本Issueにリンクする。

## 実施手順

1. NE-06のモデルとNE-07のrailを本番document ID/revisionに接続する。PoC固定コメント文字列を入力UIへ置き換える。
2. コメントの作成・編集・削除・表示とローカル永続化を実装する。保存先とschema versionを記載し、コード本文へ注入しない。
3. 折返し/折畳み時の位置、Undo後のanchor復元、外部変更時のorphan表示を接続する。
4. 再起動と同名ファイルを持つ別project/worktreeで混線しないことを確認する。

## 完了条件・検証

1. コメントを付けた実ファイルを編集/Undo/再起動して対象と本文が保持される。
2. 別worktreeにコメントが漏れず、対象削除時にはorphanと分かる。
3. ホバー/選択で全文コピーせず、UIに元PoC専用ボタンや固定データが残らない。

## 対象外

クラウド共有、他人へのコメント送信。

## 成果の引き継ぎ

変更ファイル、成功コミットSHA、実行コマンド、期待値と実結果、証跡へのリンクを追記する。必須項目が未検証ならdoneにしない。失敗時は再現手順・影響・不足条件を記録する。既存ユーザー変更をstageしない。push/外部公開はしない。
