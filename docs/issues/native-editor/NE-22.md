# NE-22: 通常エディタとdiffをネイティブ既定へ切り替える

- 状態: open
- 種別: 本番実装
- 依存: [NE-21](NE-21.md)
- 担当範囲: 設定default、移行・rollback導線、文書
- 作成日: 2026-09-08

## 目的・着手条件

通常エディタとdiffをネイティブ既定へ切り替える。調査報告やPoCだけでは完了にならない。Clairの本番コードへ実装し、製品経路で検証する。
[共通ルール](README.md)を読み、依存の成功SHAを含む隔離worktreeで作業する。NE-13の判断が不採用ならCodeEdit依存の本番実装を開始せず、代案を決定する追加Issueを作る。未達ゲートを無視しない。
UI変更は既存のClairデザインを維持する。新規UIが必要な場合は該当design/mock skillに従って先に仕様を確立し、本Issueにリンクする。

## 実施手順

1. NE-21で合格した対象のみnativeを既定にする。通常編集/diffを別flagにし、未達なら本Issueをblockedにする。
2. 既存ユーザーの明示的エンジン選択を尊重し、設定未指定のみ新defaultを使う。未保存本文の存在するタブを実行中に作り直さない。
3. 設定からWebへ戻せる導線を残し、切替時のIME/dirty/Undo保護を確認する。
4. ADRを実装済みの構成へ更新し、利用者向けに制限と戻し方を記録する。

## 完了条件・検証

1. 新規/既存設定の起動で意図したdefaultになり、明示的設定は保持される。
2. 未保存文書とdiff比較対象を失わずnative/Webの切替ができる。
3. Stable/Devのローカルbuildとsmokeが通り、rollback手順を別の人が再現できる。

## 対象外

push、公開リリース、Web fallback削除。

## 成果の引き継ぎ

変更ファイル、成功コミットSHA、実行コマンド、期待値と実結果、証跡へのリンクを追記する。必須項目が未検証ならdoneにしない。失敗時は再現手順・影響・不足条件を記録する。既存ユーザー変更をstageしない。push/外部公開はしない。
