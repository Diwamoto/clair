# Investigations

ADRやproject designを決めるためのspike、比較実装、互換性調査を置きます。

推奨パス:

```text
docs/investigations/<project_code>-<topic>/README.md
```

調査は、判断したい問い、比較条件、再現手順、観測結果、制約、推奨を分けて書きます。調査結果そのものは決定ではありません。結論を採用する場合はproject designまたはADRから参照します。

作成には [investigation template](../_templates/investigation.md) を使います。
