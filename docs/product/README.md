# Product

Clairが解決する問題、目指す利用体験、製品原則、scopeを置きます。

技術方式や実装順序ではなく、方式が変わっても残る目的を記述します。個別projectの要件は `docs/projects/`、技術選択の理由は `docs/decisions/` に置きます。

正本文書:

- [Vision](vision.md): 対象ユーザー、解決する問題、望む成果
- [Product principles](principles.md): 判断に使う安定した製品原則
- [Scope](scope.md): cutover条件、later、out-of-scope

複数milestoneをまたぐ実装順序は
[Clair v2 roadmap](../plans/clair-v2-roadmap.md)を参照します。
